# Smoker

The Smoker dries compatible meat and fish using wooden sticks as fuel.

## Features

- 30 food attachment slots
- Wooden-stick fuel
- Functional thermometer
- Openable main doors, individual doors, vents, and fuel drawer
- Normal and static kit variants

## Operation

1. Deploy the Smoker.
2. Add meat or fish to its food slots.
3. Add wooden sticks to the fuel slot.
4. Ignite it and close all doors.
5. Let the Smoker reach **100 degrees C**.

Food changes to the dried stage only when the Smoker is at maximum temperature and the doors are closed. Opening the doors interrupts effective processing and changes the smoke effect. Each fuel update consumes wooden sticks as the stored burn energy runs down.

Both variants run from wooden-stick fuel; neither requires an external electrical connection.
