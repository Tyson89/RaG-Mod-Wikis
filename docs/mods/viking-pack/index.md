# RaG Viking Pack

RaG Viking Pack adds Viking-themed weapons, armor, clothing, storage, coins, utility items, and deployable props. Its scripted systems include a fuel-burning lantern, a threat-warning raven, a noise-producing war horn, a consumable rejuvenator, coin conversion, and a craftable storage shelter.

## Feature summary

| System | Current behavior |
| --- | --- |
| Viking Shelter | Crafted from three wooden planks and five wooden sticks, deployed from a kit, and provides `10 × 50` cargo. |
| Viking Lantern | Burns attached rags or lard, emits a large light, and can be extinguished with supported liquids. |
| Viking Raven | Worn in the armband slot; warns when dangerous animals or mod-defined special infected enter a 300-meter trigger. |
| Viking Horn | Five-second horn action plays a synchronized sound and creates strong AI-attracting noise. |
| Viking Idun | Single-use rejuvenator for self or another player. |
| Viking Coins | Nine stackable denominations, a dedicated coinbag, and timed denomination-conversion actions. |
| Equipment | Custom melee weapons, helmets, armor pieces, leather clothing, belt pouches, containers, and decorations. |
| Placeables | Shelter, table, firepit, sundial, and warbanner kits. |

## Required dependency

[RaG Core](../core/index.md) is required on server and clients. The root `Viking_Pack` addon declares `RaG_Core` in `CfgPatches.requiredAddons[]`; DayZ resolves addon/PBO ordering from that dependency.
